03 / ABOUT

Why Fen?

A fen is a type of wetland. The name fits the moss greens, blue backgrounds and earthy reds in this scheme.

Dusk pairs a dark blue background with ivory text. Dawn uses a pale green background and darker accents.

Fen is a general purpose palette for editors, terminals and interfaces. Base16 and Base24 provide common role mappings; CSS, Kitty and Noctalia exports are also available.

Installation notes +

Noctalia v5: save the JSON as ~/.config/noctalia/palettes/Fen.json. Set source = "custom" and custom_palette = "Fen" under [theme]. For v4, use ~/.config/noctalia/colorschemes/Fen/Fen.json and select Fen in the color scheme settings. Noctalia documentation ↗

Base16 / Base24: these are scheme files for a compatible Tinted Theming builder. Generate the configuration for your application using its template; the YAML itself is not an editor plugin. Tinted Theming documentation ↗

CSS: load fen.css, add data-fen="dark" or data-fen="light" to your root element, then use var(--fen-moss).

Kitty: place the selected .conf next to your kitty.conf and add include fen-dusk-kitty.conf (or the Dawn file). Reload your configuration.
